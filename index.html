Printer Troubleshooting Guide
วิธีแก้ปัญหาการติดตั้ง Printer
บน Windows 11
คู่มือแบบสไลด์สำหรับไล่ตรวจสอบและติดตั้ง Printer พร้อมภาพประกอบและวิดีโอสาธิต
HP LaserJet P1102 • Step-by-Step
01 / Problem
อาการของปัญหา
HP LaserJet P1102 บน Windows 11 ติดตั้ง Driver แล้ว แต่ระบบยังไม่มองเห็นเป็น Printer
อาการที่พบ
  • เสียบ USB แล้วเหมือนมี Driver ติดตั้งอยู่ในตัวเครื่อง และมีหน้าต่างติดตั้ง Driver เด้งขึ้นมา
  • ติดตั้ง Driver แล้ว แต่ Windows 11 ไม่แสดงอุปกรณ์เป็น Printer
  • ลอง Windows Update แล้ว
  • ดาวน์โหลด Driver จากเว็บไซต์มาติดตั้งแล้ว
  • ลอง Add Printer แบบ Manual แล้ว
  • อัปเดต Firmware แล้ว
แนวทางแก้ไข

ลบของเดิมให้หมดก่อน

ลบ Printer จาก Devices and Printers และลบอุปกรณ์ที่เกี่ยวข้องจาก Device Manager จากนั้น Restart ก่อนเข้าสู่ขั้นตอน Driver และ HP Smart Install

ลำดับนี้เป็นขั้นตอนหลักของการแก้ปัญหา
02 / Step 1
ลบ Printer จาก Devices and Printers
STEP 01

ลบ Printer เดิมออกจาก Windows

เปิด Control Panel → Devices and Printers

  • ค้นหา HP LaserJet P1102
  • คลิกขวา → Remove device
  • หากมี P1102 ซ้ำหลายรายการ ให้ลบออกทั้งหมด
03 / Step 2
ลบอุปกรณ์จาก Device Manager
STEP 02

Uninstall อุปกรณ์ HP P1102 ที่เกี่ยวข้อง

คลิกขวา Start → Device Manager แล้วตรวจสอบอุปกรณ์ที่เกี่ยวข้อง

  • Printers
  • Print queues
  • Universal Serial Bus controllers
  • Other devices
  • คลิกขวาอุปกรณ์ที่เกี่ยวข้อง → Uninstall device
  • หากมีตัวเลือก Attempt to remove the driver for this device ให้เลือกด้วย
04 / Step 3–4
ถอด USB และ Restart Windows
STEP 03

ถอดสาย USB

หลังลบ Printer และอุปกรณ์จาก Device Manager แล้ว ให้ถอดสาย USB ของ HP LaserJet P1102 ออกจากคอมพิวเตอร์ และยังไม่ต้องเสียบกลับ

STEP 04

Restart Windows 11

Restart คอมพิวเตอร์ 1 ครั้ง เพื่อให้ Windows โหลดระบบใหม่และเคลียร์การเชื่อมต่อของอุปกรณ์เดิม

05 / Step 5
ดาวน์โหลดและแตกไฟล์ Driver
STEP 05

ดาวน์โหลด Driver หลัง Restart

ดาวน์โหลด Driver สำหรับ HP LaserJet P1102 แล้วแตกไฟล์ออกมา เตรียมโฟลเดอร์สำหรับเข้าสู่ Utility

  • ดาวน์โหลด Driver ให้ตรงกับรุ่น P1102
  • แตกไฟล์ Driver
  • เตรียมโฟลเดอร์ที่แตกไฟล์ไว้สำหรับขั้นตอนถัดไป
06 / Step 6
Disable HP Smart Install
ต้องทำขั้นตอนนี้ก่อนเริ่มติดตั้ง Driver ใหม่
STEP 06

ใช้ HP Smart Install Control Utility

  1. เข้าไปยัง Driver ที่ดาวน์โหลดมาและแตกไฟล์ไว้
  2. เปิดโฟลเดอร์ Utility หรือ UTIL
  3. เปิดโปรแกรม HP Smart Install Control Utility
  4. เชื่อมต่อสาย USB ของ HP LaserJet P1102 เข้ากับคอมพิวเตอร์
  5. โปรแกรมจะค้นหา Printer โดยอัตโนมัติ
  6. เลือก HP LaserJet P1102 เครื่องที่มีปัญหา
  7. กด Next
  8. กด Disable
06 / Step 6 — CHECK
ตรวจสอบสถานะให้เป็นสีแดง
หลังจากกด Disable

รอจนสถานะเป็นสีแดง 🔴

เมื่อสถานะของเครื่องเปลี่ยนเป็น สีแดง แล้ว ให้ปิดโปรแกรมได้เลย

ไม่ต้องทำขั้นตอนอื่นเพิ่มเติมใน Utility เมื่อสถานะเป็นสีแดง
07 / Step 7
ติดตั้ง Driver ใหม่
เมื่อ Disable HP Smart Install และสถานะเป็นสีแดงแล้ว จึงเริ่มติดตั้ง Driver
STEP 07

ติดตั้ง Driver ตามขั้นตอนปกติ

  • กลับไปยังโฟลเดอร์ Driver ที่แตกไฟล์ไว้
  • เปิดไฟล์ Setup / Installer
  • ดำเนินการติดตั้งตามขั้นตอนของโปรแกรม
  • รอจนการติดตั้งเสร็จสมบูรณ์
  • ตรวจสอบว่า Windows 11 มองเห็น HP LaserJet P1102 เป็น Printer
🖨️
08 / Test
ตรวจสอบและทดสอบ Printer
FINAL CHECK

ตรวจสอบผลการติดตั้ง

  • เปิด Settings → Bluetooth & devices → Printers & scanners
  • ตรวจสอบว่าพบ HP LaserJet P1102
  • ตรวจสอบ Device Manager ว่าไม่มีเครื่องหมาย ! สีเหลือง
  • สั่ง Print Test Page เพื่อทดสอบการพิมพ์
